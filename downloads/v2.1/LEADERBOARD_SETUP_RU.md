# Как запустить общую таблицу лидеров «Номерного клуба»

Игра устанавливается на Android и Windows. На сервере запускается только таблица лидеров: она принимает результаты и хранит общую базу игроков. Все игроки, указавшие один адрес сервера, видят одну таблицу.

Публичный сервер пока не размещён. Эта инструкция рассчитана на новый VPS с **Ubuntu 24.04 LTS**, домен или поддомен и доступ по SSH. VPS и домен приобретаются у выбранного вами провайдера. Для небольшой группы достаточно начать с 1 CPU, 1 ГБ RAM и диска 10 ГБ.

## 1. Скачайте файлы сервера на свой ПК

Скачайте **PlateClub-Leaderboard-Server.zip** рядом с обновлением игры. Внутри находятся папка `server` и эта инструкция. Если у вас уже есть исходники Godot, используйте их папку `server`: файлы одинаковые.

На VPS не нужны Godot, APK и Windows EXE. Нужны только `leaderboard.py`, `Dockerfile`, `compose.yaml` и `Caddyfile` из папки `server`.

## 2. Подготовьте VPS и домен

Создайте VPS с Ubuntu 24.04 LTS. Провайдер выдаст IP и способ входа по SSH. Не публикуйте пароль или SSH-ключ.

В DNS-настройках домена добавьте **A-запись**: имя `leaders`, значение — IP вашего VPS. Например, для вашего домена получится `leaders.ваш-домен.ru`. Если есть AAAA-запись, она тоже должна вести на этот VPS; иначе удалите неправильную запись. Дождитесь обновления DNS.

В сетевом экране провайдера разрешите входящие TCP-порты **22** для SSH и **80, 443** для сайта и HTTPS. Порт **8765** открывать не нужно: он доступен только внутри Docker.

В командах ниже замените `SERVER_IP` на IP сервера, а `leaders.example.com` — на свой настоящий поддомен. `example.com` служит только примером.

## 3. Загрузите архив на сервер

Откройте PowerShell в папке, куда скачали архив. Выполните:

```sh
scp PlateClub-Leaderboard-Server.zip root@SERVER_IP:/root/
ssh root@SERVER_IP
```

При первом подключении проверьте отпечаток SSH-ключа по информации провайдера. Если провайдер выдал пользователя вместо `root`, используйте его имя и домашнюю папку; для системных команд нужен `sudo`.

Дальнейшие команды выполняются **в терминале VPS**, а не на вашем игровом ПК.

## 4. Установите Docker и распакуйте сервер

На новом VPS Ubuntu 24.04 под `root`:

```sh
apt update
apt install -y docker.io docker-compose-v2 unzip curl
systemctl enable --now docker
docker compose version
mkdir -p /opt/plate-club
unzip /root/PlateClub-Leaderboard-Server.zip -d /opt/plate-club
cd /opt/plate-club/server
```

Пакет `docker-compose-v2` доступен в репозитории Ubuntu Universe; обычно он уже включён у облачного образа. Если пакет не найден, включите Universe или установите Docker Engine и Compose по официальной инструкции: https://docs.docker.com/engine/install/ubuntu/ . Для другой ОС используйте её инструкцию Docker.

Если вы включаете UFW, сначала разрешите SSH и затем веб-порты:

```sh
ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
```

На сервере с уже настроенными сайтами сначала проверьте, что порты 80 и 443 свободны: этот комплект запускает свой Caddy.

## 5. Укажите свой домен и запустите

Оставаясь в `/opt/plate-club/server`, создайте файл `.env`:

```sh
printf 'LEADERBOARD_DOMAIN=leaders.example.com\n' > .env
docker compose up -d --build
docker compose ps
docker compose logs --tail=50 caddy
```

Перед выполнением замените домен в первой строке. Указывайте только доменное имя, **без `https://` и без пути**. Caddy автоматически получает и продлевает сертификат при правильных DNS и доступных портах 80/443.

Проверьте из браузера на ПК:

```text
https://leaders.example.com/health
```

Либо на VPS:

```sh
curl https://leaders.example.com/health
```

В JSON-ответе должно быть `"ok": true`. Пустая таблица до подключения первого игрока — нормальна. Не отключайте проверку сертификата, если HTTPS не работает: проверьте DNS и логи Caddy.

## 6. Подключите игру

1. Запустите игру на Android или Windows.
2. Откройте **☰ → Лидеры**.
3. Впишите имя игрока и адрес **https://leaders.example.com** со своим доменом.
4. Сохраните настройки и нажмите **Синхронизировать**.
5. Дайте друзьям этот же HTTPS-адрес. Каждый использует своё имя и свою установку игры.

URL нужен без `/health`, `/v1` и других добавлений. Телефон должен иметь доступ к интернету. После новых достижений нажимайте синхронизацию, чтобы отправить результат. Основная игра остаётся доступной офлайн.

Токен профиля создаётся автоматически и хранится в приватном сохранении игры. Не передавайте друзьям своё сохранение: это также передаст ваш профиль. Удаление приложения или сохранения создаст новый профиль; Windows и Android используют отдельные профили.

## 7. Обслуживание и резервная копия

Команды выполняются в `/opt/plate-club/server`:

```sh
docker compose logs --tail=100
docker compose restart
```

Обновление файлов сервера: загрузите новый архив, распакуйте с `unzip -o` в ту же папку, затем выполните `docker compose up -d --build`. Сохраните существующий `.env` и Docker volume `scores`. Не используйте `docker compose down -v`: эта команда удаляет базу игроков и данные сертификатов.

Для копии базы без остановки сервера используйте SQLite backup:

```sh
docker compose exec -T leaderboard python -c "import sqlite3; s=sqlite3.connect('/data/leaderboard.sqlite3'); d=sqlite3.connect('/data/backup.sqlite3'); s.backup(d); d.close(); s.close()"
docker compose cp leaderboard:/data/backup.sqlite3 ./leaderboard-backup.sqlite3
```

Затем скачайте копию на свой ПК из отдельного окна PowerShell:

```sh
scp root@SERVER_IP:/opt/plate-club/server/leaderboard-backup.sqlite3 .
```

Храните её отдельно от VPS. Не копируйте только основной SQLite-файл работающего сервера: свежие записи могут находиться в WAL. Перед восстановлением остановите сервер; сохраните текущую базу отдельно и замените файлы базы согласованной резервной копией. Если не знакомы с Docker volumes, воспользуйтесь помощью администратора. Обновляйте ОС, Docker и контейнеры.

## Если не работает

- **HTTPS не открывается:** проверьте A/AAAA-записи, TCP 80/443, занятость портов и `docker compose logs --tail=100 caddy`.
- **`health` отвечает, а игра не подключается:** проверьте адрес в игре. Нужен `https://домен`, без `/health`. Нажмите сохранение и синхронизацию; проверьте интернет на устройстве.
- **Таблица пустая:** сначала синхронизируйте хотя бы один настоящий профиль. Тестовых или вымышленных игроков в таблице нет.
- **Команда Compose не найдена:** установите именно Compose v2; команда пишется `docker compose`, с пробелом.
- **После обновления исчезли результаты:** проверьте, что запуск идёт из прежней папки и используется прежний volume `scores`. Не удаляйте volumes.

## Проверка на одном ПК без VPS

Установите Python 3.10+ и из папки `server` выполните:

```sh
python leaderboard.py --host 127.0.0.1 --port 8765 --database leaderboard.sqlite3
```

В игре **на том же ПК** укажите `http://127.0.0.1:8765`. Для телефона этот адрес обозначает сам телефон. Для общей таблицы Android/Windows используйте публичный HTTPS-сервер по шагам выше.

## Как считаются очки

Выпуски × 5 + контракты × 250 + разные машины × 500 + выпущенные легендарные номера × 1 000. Сервер хранит лучший результат каждого профиля и отдаёт 100 лучших настоящих игроков.

Запросы требуют индивидуального токена, в базе хранится его хеш. Сервер проверяет формат статистики, границы значений и частоту запросов. Игра работает офлайн, поэтому таблица доверяет клиентской статистике в этих пределах; она не является полноценной защитой от изменения сохранений.
